## ✨ Features

- **3D Hero Scene** — Interactive Three.js background with animated 3D objects and particles
- **3D About Card** — Interactive profile card with tilt effects and animated elements
- **Tech Orbit** — Interactive technology visualization for development skills
- **Themed Project Scenes** — Individual 3D canvas scenes for featured projects
- **Smooth Animations** — Interactive transitions and animated UI elements
- **Responsive Design** — Optimized for desktop, tablet, and mobile screens
- **Dark Theme** — Modern dark interface with gold accent colors
- **Resume Download** — Direct access to my downloadable resume
- **Contact Section** — Contact information and social media links
