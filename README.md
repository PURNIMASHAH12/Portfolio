## 🚀 Getting Started

This portfolio is built using HTML, CSS and JavaScript, so no package installation or build process is required.

### Clone the Repository

```bash
git clone https://github.com/PURNIMASHAH12/Portfolio.git
```

### Open the Project

```bash
cd Portfolio
```

### Run Locally

Open `index.html` directly in your browser.

Or use **Live Server** in VS Code:

1. Open the Portfolio folder in VS Code
2. Open `index.html`
3. Right-click inside the file
4. Select **Open with Live Server**

## 🌐 Deployment

This portfolio can be deployed as a static website using **Netlify**.

### Deployment Flow

```text
VS Code
   ↓
Make Changes
   ↓
git add .
   ↓
git commit
   ↓
git push origin main
   ↓
GitHub
   ↓
Netlify
   ↓
Updated Portfolio
```

After connecting the GitHub repository to Netlify, new commits pushed to the `main` branch can automatically trigger a new deployment.
