🚀 Getting Started

This portfolio is a static website built using HTML, CSS, and JavaScript.

No Node.js installation or package installation is required.

1. Clone the Repository
git clone YOUR_GITHUB_REPOSITORY_URL
2. Open the Project
cd Portfolio
3. Run the Website

You can simply open:

index.html

in your browser.

Recommended: VS Code Live Server

For easier development:

Open the project in VS Code
Open index.html
Right-click index.html
Select Open with Live Server

The website will open automatically in your browser.

🌐 Deployment

The portfolio can be deployed as a static website using Netlify.

Netlify Deployment
Push the project to GitHub
Log in to Netlify
Select Add new project
Choose Import an existing project
Connect your GitHub account
Select the portfolio repository
Set the publish directory to:
.
Leave the build command empty
Deploy the site

After deployment, Netlify provides a public URL that can be added to the GitHub profile and portfolio README.
